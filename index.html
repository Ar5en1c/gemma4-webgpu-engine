Gemma 4 WebGPU Engine

A clean-room inference engine for Gemma 4 E2B that runs entirely in your browser. Nothing you type leaves this machine. This page profiles your GPU and, if you ask it to, benchmarks the engine on it.

1. Device profile

No download, a few seconds. It fills memory in steps to find where this device stops, so on a phone it may reload the tab. That is the answer, not a bug: the page will tell you where it stopped when it comes back.

The second button answers a different question: the profile measures GPU buffers, this measures ordinary memory. On a phone it is expected to end the tab, and the number is written down before each step, so come back and copy the trail.

2. Benchmark

This downloads about 2 GB of model weights from Hugging Face on first run, then caches them in this browser. Do not start it on a metered connection. It needs roughly 3 GB of free memory, so most phones will fail here.
Apache-2.0. Weights are Google's Gemma 4, also Apache-2.0, fetched directly from Hugging Face. Source.
